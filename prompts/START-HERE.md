# Start here

Use this folder from a website repository with the blueprint available as reference. You do not need to choose databases or learn deployment jargon first.

1. Follow [getting started](../docs/01-getting-started.md) to fork/clone safely and install prerequisites.
2. Give your agent the complete [website-builder](website-builder.md) prompt. Tell it your website idea in one sentence. It will ask a few questions, record a plan, and explain choices.
3. Review the generated `.project/requirements.md` and `.project/roadmap.md`. Correct misunderstandings before implementation.
4. Implement and test one milestone at a time. Use [security-auditor](security-auditor.md) for review and [deployment-reviewer](deployment-reviewer.md) before production.
5. Use [resume-project](resume-project.md) next session and [maintenance-agent](maintenance-agent.md) after launch.

If you want to modify this blueprint rather than build a website, say that explicitly. A fork of the blueprint should remain a documentation project until you request implementation. Never paste passwords, tokens, or private account records into a prompt.
